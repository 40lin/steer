# 后验匹配引导：独立探索结果

本实验是第二版结果出来后提出的新假设，不改写第二版 p=.78 的主分析。价格固定 .78，按实际容量计费，动态方法的 rho 始终为 0；唯一调整是原最大容量匹配之间的优先顺序。每轮用公开申报形成临时后验，先最大化预测完成任务数，再以完成价值破同分。总计 400 轮，不训练策略。

验证集在 12 个固定候选（uniform/priority0/priority1 × 四个 rho）中选出 **priority0_r0**：优先让 buyer0 获得 3 单位容量 VM，rho=0。它同时满足验证收入、任务数和价值不低于旧固定规则。固定选择后才运行独立测试。

同计费、同 rho 时，学习型联盟组的动态和固定匹配结果完全相同。精确联盟最优反应下，所有新匹配规则均为 R=1560、J=800、V=3800；比旧固定收入多 200，但动态相对同机制固定规则额外增益为 0。资源可共享后，VM 归属不改变联盟获得的总容量和联合效用，因此这里的匹配调整不能产生额外抗联盟效果。

市场 D 相对强固定规则呈现价值提高、任务数和收入下降。该规则只依据当期预测服务选匹配，没有优化长期参与与收入；这些结果不支持预定的增收且服务无损目标。

canonical 与 tabular 的逐世界指标完全一致：因为所有方法的 rho 都固定，访问的只有一个经济状态，两个学习表示在本实验等价。两份结果是复现检查，不是两个独立泛化证据。

代码、验证选择和数据均已冻结并通过哈希复核。验证耗时 14.71 秒，测试生成 72.80 秒，协议冻结至全部统计完成约 90.42 秒。完整区间和逐类型结果见 summary.json、comparisons.csv、metrics.csv、type_results.csv。
