# 固定分配下的完成激励：两轮实验结果

本报告对应 V4/V5 已完成的独立模拟实验。结论是：**加入公开申报条件的完成奖励可以小幅缓解指定学习型买方的低报与成功低报交换，但奖励尚未收回成本，动态策略没有超过充分调优的固定奖励，更强联盟仍可套利。** 不能写成消除了低报、实现了抗共谋或保护了平台净收益。

## 1. 技术方案及与原论文的关系

平台保持既定分配映射 `A0` 与原账单不变，只增加非负奖金。`A0` 是本项目补全的最大总容量匹配、均匀破同分、`rho=0`；初始获配者仍支付 `0.2*c+0.8*b`。2024 论文给出一般函数 `A`，没有完整指定该匹配实现，所以这里只声称冻结本项目基线，没有声称完整复现原论文唯一的分配算法。

V4 按任务完成付奖，希望增加资源持有者牺牲自己任务、向低报者让渡资源的机会成本。V5 再要求指定买方的公开申报达到2或3才有领奖资格；该条件不改变资源资格、基础收费和交易规则，也不代表真实需求已经得到验证。交易后完成的用户仍可领奖。

平台策略只使用公开申报、初始分配、账单、完成标记、自己的奖励与预算历史。真实需求、加入意愿、交易、转账和买方 Q 值不可作为部署输入。低报和交换标签仅用于离线仿真的训练目标和评价。平台能观察的“按时完成”在当前模型中用最终容量足够代理，未模拟实际任务运行时间。

技术细节见 [V4完整方案](v4_technical_design.md)、[V4协议](v4_incentive_protocol.md)、[V5扩展协议](v5_conditional_protocol.md)。三人竞争两台 VM，参与方自主决定加入交易组并可拒绝亏损的交易；交易失败来自资源机会成本与接受约束，不是人为设置失败概率。主交易要求同正申报组，另检验组内任意补偿及跨申报全共享联盟。

## 2. 实验与统计范围

两版分别训练10个种子，每种子1,024,000个市场时隙，合计20,480,000；V4有39种固定/预定对照，V5有103种。验证和测试流相互独立，两版也使用不同随机流。每条轨迹400轮，前200轮奖励，后200轮撤奖，主硬预算50。其他预算0/10/25/100用于同一主检查点的预算迁移，不重新训练或按测试重选。

学习型测试24种固定市场/学习率组合，每类100个配对 world。每版92个正式测试 NPZ 均保留于本地。统计为10,000次配对交叉 bootstrap，重抽完整 world 和训练种子，不把轮次或买方当作独立重复；模型类型目录固定。下列区间为双侧95%，只描述这个模拟目录中的随机不确定性。

低报率以活跃买方为分母；“成功低报交换参与率”以全部买方时隙为分母，只计含低报成员且实际执行严格获益交易的组成员。它不是现实联盟识别率，也不等于所有资源共享有害。另报告全部时隙低报、退出、高报、加入意向和服务量，避免把退出或标签变化算作诚实。

预声明的较强主门槛是撤奖期两种行为率各相对减少20%，完整期与撤奖期任务数均不降且不超预算。**20%是研究基准，不是用户提出的唯一有效性要求。** 未达20%时仍报告较小的真实改善。动态额外价值须相对强固定对照实现更低成本且行为与服务不恶化。

## 3. 主结果：V4与V5各自的配对比较

行为比例取撤奖后的200轮，其余取完整400轮。两版的无奖励基线来自不同测试流，不能把版本差直接当作配对因果效应。

|指标|V4 无奖励 → 引导|V5 无奖励 → 引导|
|---|---:|---:|
|低报率|52.2209% → 52.1311%|52.1970% → 51.2660%|
|成功低报交换参与率|3.1978% → 3.2031%|3.2069% → 3.0983%|
|任务完成量|702.5475 → 703.7922|702.3200 → 703.3088|
|实际奖励成本|0 → 44.2413|0 → 41.9550|
|平台净收款|1468.3198 → 1426.3076|1468.7279 → 1437.7088|
|选中学习策略／回退固定的种子|2／8|0／10|

V4的完成奖使撤奖低报率仅下降约0.0898个百分点，成功低报交换没有下降；发奖期间该交换率反而增加约0.0474个百分点。全期净收款下降42.0122，区间[-43.0073,-41.1135]。详见 [V4独立报告](v4_results.md)。

V5验证选择的是 `fixed_22_uniform`：向账号1提供金额1的“申报至少2且完成”的奖励，按均匀预算释放日程投放。主预算下10个训练种子全部回退这一固定方案，因此下列改善归于简单条件奖励，不能归于学习出的动态策略。

|V5 相对无奖励的差值|奖励期200轮|撤奖期200轮|
|---|---:|---:|
|低报率，百分点|−1.6493 [−1.6998,−1.6008]|−0.9310 [−0.9929,−0.8699]|
|成功低报交换率，百分点|−0.1249 [−0.1585,−0.0917]|−0.1086 [−0.1467,−0.0717]|
|完成任务数|+0.7721 [+0.6808,+0.8625]|+0.2167 [+0.1104,+0.3217]|
|平台净收款|−35.1746 [−35.4218,−34.9342]|+4.1555 [+3.8535,+4.4610]|

撤奖期低报和成功交换分别相对减少1.78%和3.39%，普通方向改善获得支持，但均未达到20%。全期任务数增加0.9888，区间[0.8479,1.1271]。奖金41.955只带来额外基础收款10.9359，最终净收款减少31.0191，区间[-31.4275,-30.6126]，约下降2.11%。不能只报告撤奖期新增收入、遗漏前期奖励成本。

V5撤奖期高报率还增加约0.1982个百分点，退出率减少约0.1423个百分点。因此低报减少并不等于全面诚实；下降也不是靠大量退出实现。四个价值族及两档学习率的低报和交换点估计均下降，但这不保证每个类型、每个买方都受益；完整分组与角色服务区间在参考包内保留。

## 4. 降低奖励成本的实际代价

下表是同一个 B50 选定方案在不同预算下的诊断；各预算另行验证选出的固定参考也完整保存在[成本表](../results/reference/incentives/v5/analysis/cost_frontier.csv)。没有按照测试结果改选主方案。

|预算上限|实际奖励|撤奖低报率|撤奖成功交换率|全期任务数|平台净收款|
|---|---:|---:|---:|---:|---:|
|0|0|52.1970%|3.2069%|702.3200|1468.7279|
|10|3.1688|52.0248%|3.1927%|702.4433|1466.4282|
|25|17.3958|51.7383%|3.1571%|702.7279|1456.0289|
|50|41.9550|51.2660%|3.0983%|703.3088|1437.7088|
|100|72.6425|50.7834%|3.0703%|703.8329|1413.8290|

成本降至3.17时，低报仍有小幅下降，但成功交换差的95%区间跨零，不能确认两项都改善。成本约17.40时，两项撤奖行为差的区间均低于零：低报减少0.4586个百分点、成功交换减少0.0498个百分点；净收款仍减少12.6990。这个探索性结果说明可以用较少奖励换取较小效果，不说明已求得最低成本，也不能由多个预算中挑出的显著性替换主检验。

主预算50下动态和强固定完全相同；在其他预算下，花费更少的迁移方案也未同时满足相对该预算强固定的行为和服务非劣约束。没有验证“动态调整比固定奖励更好”。

## 5. 为什么仍不能抗强共谋

V4阶段枚举中，全体加入并报1的策略在12物理市场×16奖励的192种配置下，仍分别是受限交易和自由补偿响应的纯纳什均衡。对不降低任何获奖者完成概率的获益交换，非负完成奖励无法抬高让渡机会成本，甚至可能帮助交换。

V5新增24个条件奖励后，部分全报1均衡可以被打破，但在受限交易288种配置中仍有240种保留该均衡，同申报自由补偿中有252种保留。所有诚实申报配置也仍存在有利的单人偏离。打破某个低报均衡，不等于排除所有低报或所有联盟。

在逐阶段精确同申报联盟响应下，实际选择的V5奖励没有改变全报1结果：低报率仍100%，奖金支出0，400轮净收款1040、完成任务800。联盟选择不领奖，继续低价获得服务。

再允许跨不同申报共享所有已租VM和任意内部补偿，冻结的V5策略在新随机流850061上实际回放得到：

|400轮强联盟回放|无奖励|V5已选策略|
|---|---:|---:|
|完成任务数|800|800|
|实际奖励|0|50|
|平台净收款|1040|1016.6127|
|奖励期低报率|100%|94.4444%|
|撤奖期低报率|100%|100%|

该联盟是外生绑定的压力场景，不用成员常数评价“联盟形成率”。它能够分工申报、交换完成并领取奖励；表面低报率暂时下降，并没有保护平台收入。阶段枚举还保留“需求2者报3领奖，再换资源完成”的具体[套利见证](../results/reference/incentives/v5/exact_audit/overreport_reward_swap_witness.json)。

这里存在一个更根本的边界：全体报1始终能以每轮2.6租满两台VM，通过共享实现最大可完成价值 `Vmax`。在任意非负奖励下，理性联盟最优效用至少为 `Vmax−2.6`；又有 `联盟效用+平台净收款=完成价值≤Vmax`，所以平台期望净收款不超过2.6/轮。这个上界依赖本模型的资源、原分配和非负奖励假设，不是所有云平台的普遍定理，也不是每条随机路径的上限。它解释了为什么单靠更聪明地发奖无法解决此强联盟的收入损失。

## 6. 对论文目标的判断

1. **降低低报与共谋程度：部分达到。** V5在指定学习与同申报交易模型中，奖励期和撤奖期都出现小幅改善；不能推广为诚实均衡、联盟解体或自由跨组共享下有效。
2. **引导成本尽可能低：只得到成本—效果权衡，尚未实现最低成本。** 更少奖励仍可带来较小的行为改善，但目前测试的正奖励方案都降低全期平台净收款；动态方法未取得额外优势。

下一步的研究应先明确真实交易的限制与可持续性：只有奖励能使关键伙伴真实损失更多，且联盟无法无损替换伙伴时，机会成本路线才可能有效。不能为了获得正结果而人为禁止跨申报交换、假设联盟一定失败，或把真实需求当作平台可观察数据。若坚持任意共享、自由补偿和仅非负奖励，本模型已有上述收入上界，继续扩大PPO训练本身不能跨过它。
