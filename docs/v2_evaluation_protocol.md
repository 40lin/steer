# 第二版实验的公平比较与成功标准

本文件冻结第二版的度量、比较和解释规则。审查者已知第一版的正向与失败结果，但在写入本文件前未读取第二版的验证或测试输出。第一版总体收入改善不代表防共谋：其完成任务数下降，且精确联盟响应与前瞻伪装均可使平台受损。

本文件先冻结**评估层**；候选机制、可调参数、筛选规则、软件哈希与测试随机流必须在各实验臂第一次测试前另存机器可读清单。尚未确定的候选不得被称为已经完整预注册。后续修订只追加版本和揭盲状态，不覆盖本次规则。

## 1. 必须区分的三个研究问题

1. **减少低报造成的逃费**：联盟能否以更少的付款，获得相同的一组已完成作业？
2. **抵御反向操纵**：联盟是否能够牺牲短期利益，诱导平台改变未来规则，从而提高完整时域的联盟总效用？
3. **增收且保持服务**：扣除所有激励后，平台收入是否提高，同时已完成作业和完成价值不下降？

共享虚拟机、迁移完整作业与内部转账在模型中是允许的能力，不应把共享本身当成失败或违规。联盟是否保持组织完整，也不是本实验的防逃费指标。

## 2. 模型与账本

沿用两名买方、容量为 `(3,2)` 的两台完整虚拟机、四种需求/价值市场。主时域为400轮，前200轮按10轮块调整，后200轮固定最后的规则；若新机制使用其他节奏，须作为不同实验臂明确标注。所有轮次均计入收入与联盟效用。

每一轮保存足以复核的实际分配、申报、账单、返利、作业完成标记、实际可执行配额。真实需求和私有效用只用于环境与评估，部署平台不得直接读取它们。需要可执行CPU配额或可验证使用量的新机制，必须把该物理能力作为新增假设写明，不能在原环境中只修改计分函数。

账本至少记录：

|量|定义与解释|
|---|---|
|净收款 `R`|实际支付减全部返利、补贴与已建模成本；不得把补贴前收入当收益|
|完成作业数 `J`|实际完成的作业总数，不是租到虚拟机的账户数|
|完成价值 `V`|已完成作业的模型价值之和|
|完成需求 `D_done`|已完成作业真实需求之和；不能把未完成作业需求算作已提供服务|
|租出容量 `Q_lease`|已出租物理容量，保留为资源利用诊断，不能替代 `J` 或 `V`|
|已购买配额 `Q_paid`|实际获配并受机制执行的资源权利总量；无配额机制时须写清定义，不能把低申报量直接当成已经购买的全部资源权利|
|联盟总效用 `U_C`|完成价值减对平台的净支付；联盟内部转账相互抵消|
|退出率|以全部到达买方为分母，独立报告；退出不计为诚实申报|
|激励开销 `C`|完整episode逐路径累计，另报均值、最大值与预算违反次数|

运营与切换成本继续设为零时，称模型净收款，不称已验证的商业利润。

## 3. 低报指标与共享下的身份问题

继续报告活跃买方中 `b_i < m_i` 的比例、低报量、高报率和退出率，并同时给出活跃人数分母。低报比例下降伴随大量退出，不能解释为诚实性提高。

若联盟允许迁移作业，账户标签可能交换。例如需求为3的作业可以在另一账户租下的3核权利上执行。此时某个账户满足 `b_i < m_i` 并不必然产生经济逃费。因此：

- 个体低报率是描述性行为指标，不能单独证明或否定联盟防逃费。
- 对可执行配额机制，检查每条路径的 `max(D_done-Q_paid,0)`。值为零只证明已完成需求没有超过已购买配额，不证明个体诚实，也不证明联盟没有通过优惠菜单少付费。
- 另计算“同服务最低付款”：对每一实际市场及指定已完成作业集合，枚举联合申报、匹配与可行装箱，比较实现相同服务集合时的最小净支付。收费变化后，这个最小值必须重新计算。
- 若比较的分配具有随机性，区分逐匹配保证、期望保证和指定成功概率的服务；不能用不同完成概率的服务价格冒充同服务比较。
- 若要声称个体诚实占优，需要单独检验个体偏离激励条件。降低低报率、消除配额缺口或提高平台收入都不是该证明。

## 4. 对照与收益归因

第一版最佳通用固定门槛 `rho=0.5` 是旧机制的历史参照，不是所有新机制的充分对照。每个新机制必须至少包含：

1. 原收费与分配规则下全部四类固定门槛，验证选择、独立测试。
2. 同一新机制下全部不同的固定门槛或固定菜单，且使用相同服务条件筛选。
3. 新机制的动态策略，以及同机制下无需响应历史的强预定日程。
4. 若使用后验推断，加入不使用后验的历史策略或机制相同的简单反馈。

把总收益差分解为：新固定机制相对旧固定机制的改善，以及新动态策略相对新固定机制的增量。前者是机制/收费设计价值，后者才是动态引导的证据。价格降低、配额收紧、任务拒绝或身份限制产生的效果须归到相应机制变更。

知晓真实类型的按类型最佳固定规则仅用于解释识别价值。若动态方案没有超过它，不声称已证明超出“识别类型后选规则”的轨迹控制收益。

仅在旧策略输出后增加门槛限制，是**冻结策略的控制约束消融**，不是已经重新训练的第二版强化学习算法。全部十个旧训练种子都应保留，不能挑效果最好的种子代表机制。

## 5. 成功标准

先在验证数据上选定候选和可部署的固定参照；测试数据不用于改参数、选种子或换参考。所有效应在相同市场类型和外生随机条件下配对计算。

### 增收且服务无损

对预先指定的主要比较，使用单侧95%置信下界：

- `E[R_new-R_ref]` 的下界严格大于0；
- `E[J_new-J_ref]` 的下界不小于0；
- `E[V_new-V_ref]` 的下界不小于0。

三个条件同时满足，才称“增收且任务服务不受损”。这是一项联合条件；某项失败时保留其具体折中，不通过更换服务指标补救。等效的确定性精确枚举可以直接核验不等式，无需人为添加抽样误差。

“维持至少95%的租出核时”只保留为与第一版兼容的诊断。即使通过，也不能覆盖任务数或价值下降。若另研究允许服务损失的策略，应在观察结果前声明可接受的损失幅度，并把它标为新的折中目标。

总体、独立组、联盟组、四个市场以及16个学习模型分格均报告。总体通过不能称逐类型或逐用户保证；声称抗联盟增收时，联盟组也必须通过对应条件。若声称每类型保障，则每类型都须满足，不能用高价值市场的收益补掉低价值市场的服务损失而不披露。

### 防逃费与抗操纵

- 配额缺口逐路径为零：只支持物理资源权利约束有效。
- 同服务最低付款达到预设底线：支持该模型内的防低成本拿同服务。
- 在所搜索攻击类中未发现盈利偏离：只支持“未发现该类攻击”，不构成普遍抗共谋证明。
- 任一合法前瞻策略使 `U_C` 严格增加，同时使平台收入或服务下降，足以否定对应的普遍抗操纵/无损主张。
- 报告攻击者收益与平台损失两个量。不能直接最大化平台损失来代替理性的联盟攻击，也不能把联盟获利一律视为平台受损。

如果要比较“共谋额外损失”，使用同机制、同需求/价值及同学习率的 `L=R_independent-R_coalition`，比较 `L` 的变化，并保留可能为负的结果。

## 6. 对手与统计拆分

最低响应组包括：规范资格特征的原学习器、各资格独立的表格学习器、精确单轮联盟最佳响应，以及以完整400轮总效用选择的前瞻攻击。精确单轮响应不是跨期最优响应；二者不能互相替代。

前瞻攻击需要独立的攻击训练/验证与测试流，在验证上按联盟效用选模板或参数，在新测试流上评估。若限制为89个模板，结果仅给攻击可利用性的下界。平台须在攻击历史上正常更新，而非重放正常历史或在中途重置记忆。平台和联盟的同效用破平局规则事前固定，平台悲观选择与其他选择可作为敏感性分别报告。

十个训练种子与同一组world构成交叉结构。统计沿用10,000次配对交叉bootstrap：重抽训练种子，并在每个固定类型内重抽world；同样抽样用于所有方法。16类型是固定目录，不重抽类型。精确理性响应合并重复学习率标签，只统计4个实际市场。

不同响应组或不同批量顺序如果未共享逐world外生随机数，不能声称跨响应组逐路径配对。旧测试流不得作为新候选的确认性测试。多候选可先做探索筛选，再对选中方案使用新的一次测试；不得把测试集最优者包装为预先选定方案。

## 7. 有限激励与收费边界

历史设计中的激励预算为**每完整episode逐路径最多50**，来自 `200×5×1` 的5%，不是每轮50，也不是每买方50。第一版实测返利为零；历史保持期规则为返利归零。第二版若启用激励，需明确全期预算、保持期规则和实际现金账本。

用户明确允许调整资源分配或保障规则，并配合有限激励。这没有自动等同于任意调整长期收费。新的长期价格菜单应作为明确的机制扩展陈述；不能把无限期降价称为预算50内的临时激励。若原价被当作补贴参照，所有减免都要计入预算；若改为新公布价格，则必须重做同机制固定基线，且明确不再沿用原价假设。

一个已知可行性边界是：若可执行配额等于申报量，并保留原账单 `0.2c+0.8b`，市场B要完成需求 `(3,2)` 必须每轮付5，但总完成价值仅4。无跨期外部效用时，完整400轮持续完成两任务需要累计至少400的减免才能弱参与；严格参与需要更多。预算50无法支持这一保证，保持期无返利时也不能持续支持。该边界不能靠平台学习器或更多训练消除。

## 8. 发布与解释

每个实验臂保存候选菜单、收益与服务筛选规则、预算、类型/种子、完整输出、失败情况及代码哈希。未经全套评估的候选可标为探索结果，但不能写成已验证改进。

最终报告按“原模型是否改善”“换响应后是否保持”“联盟能否利用规则”“机制变化贡献多少”“动态引导额外贡献多少”的顺序解释，不能只挑收入最好的数字。原版数据和冻结清单保持不变。
