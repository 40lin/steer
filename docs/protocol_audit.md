## 1. 本次实际回答的问题

本次先去掉返利，固定 kappa=0，检查未知异质市场下，使用公开历史的动态资格阈值，是否提高400轮累计净收款，并保持至少95%的原规则已租核时。运营和切换成本设为零，因此结果称净收款；不推断真实商业利润。

本次不是完整抗任意联盟证明，也不要求真实需求被识别或所有参与方诚实。动态动作只在每10个市场时隙的块边界更改。前200轮允许控制，共20个决策块；后200轮固定最后一个控制块的阈值，买方继续学习。全部400轮计入目标。

隐藏目录固定为4种需求/价值市场 × 独立/全体联盟 × 学习率0.05/0.2，共16类，先验均匀。2名买方、2台容量(3,2)的不可拆VM，每轮最多一台/账户；允许退出和高报。共享按整项任务装箱，禁止跨VM拼接作业，联盟可自由内部转账。代码、价格和均匀最优匹配沿用已核验的经济模型。

## 2. 必须消除的表示伪影

容量(3,2)、正报告1/2/3时，rho的不同经济规则只有4类：

原菜单0.8与1拥有完全相同资格、收费和分配，但raw-rho线性Q特征把二者当成不同状态。策略若仅通过切换这两种标签获利，不能解释为经济机制改善。本轮确认性动作空间去重，买方状态特征由规范资格类/资格指纹计算，经济等价规则必须产生相同特征。固定基线也覆盖全部4类，因此不遗漏连续rho中的其他经济规则。

仍需分别测试共享线性特征、规范类one-hot/独立表格Q、精确理性最佳响应。去重只消除等价标签问题，不证明任意函数逼近学习器的泛化结构合理。切换菜单时严禁重置Q权重、探索状态或私有记忆。

## 3. 训练、选择和封存测试

平台主算法为GRU PPO，隐藏维64，128个并行episode；每训练种子最多约2,000,000个实际市场时隙，计划10个独立训练种子。市场时隙与宏决策步数分别记账，不能把10轮宏动作当成仅一次环境交互。保持期也计入实际交互预算。平台gamma=1，奖励使用完整400轮累计净收款；保持期无自由动作，不将被事后覆盖的动作放进actor策略损失。

训练、验证、测试使用不同完整episode随机流。模型内三者共享同一有限目录F，不能将更换随机种子叫作模型外泛化。验证集每类100个worlds，共1600；最终测试每类100个全新worlds，共1600，并对所有平台训练种子及全部方法复用这些外生worlds以便配对。

每个world预先分离买方选择、联盟联合选择、匹配平局、平台动作等随机流，并按时隙索引；不要因不同方法调用随机数次数不同而使配对流无意错位。随机种子、真实类型、真实收益和Q表只供环境与审计，不可进入部署actor。平台用自己的历史运行，不强行沿用另一机制的动作历史。

固定阈值选择、反馈参数、checkpoint与超参数只依据验证集。冻结结果前确定RL部署动作使用随机采样还是argmax，并对所有RL基线采用同一预定方式；建议将argmax作为明确的部署选择，随机策略另作敏感性。不能在看到测试表现后二选一。每种训练方法均报告全部10个种子，不挑最好种子。

最终测试首次生成或开启前保存：实现版本/文件哈希、冻结配置、种子清单、每方法已选参数/checkpoint、服务选择规则、结果分析脚本哈希。本协议不授权根据测试结果继续调参并仍使用同一测试集作确认性结论。

## 4. 最低充分对照组

1. 原规则rho=0，完整400轮。
2. 所有4种固定阈值，完整400轮。主要比较对象是在验证集上、满足服务要求的候选中选择的全局最佳固定阈值；如无人通过，rho=0是预定可行回退。全部固定候选结果同时公布。
3. 按隐藏类型分别在验证集选最佳固定阈值的oracle，测试时允许oracle知道类型。它仅用于区分识别市场类型与动态改变行为轨迹的价值，不能当可部署公平基线，也不是所有动态策略的上界。
4. 时间条件open-loop策略：与主方法相同动作空间、保持规则、网络容量量级和训练交互预算，但输入仅时间、过去自身动作和内部随机性，不看用户报告、收入、分配等响应。另列可复现的周期/单次切换日程，在验证集选择，避免time-only PPO训练失败形成弱对照。
5. 简单反馈：每10轮聚合公开收入和已租容量，使用预先固定的低复杂度规则，例如分块UCB或有滞回的逐级资格调节。窗口、探索系数和服务权重只在验证集选，完整公开候选网格；不能读取隐藏类型。
6. 主历史GRU策略。若显式后验方法另行加入，必须增加同历史直接GRU而无后验的消融，不能仅与固定规则比较后宣称贝叶斯识别贡献。

对周期/单次切换的最小候选集：4种阈值的所有有序二元组合，切换时刻取0/20/40/80/120/160/200；周期长度取10/20/40/100，且每次动作至少保持10轮；后200轮统一固定第200轮阈值。大量日程的验证计算量单列，最终只提交验证选择结果到封存测试。

## 5. 服务约束、主要终点和成功层级

令R为400轮累计净收款，Q为400轮已租核时，Q0为同目录、同外生world在rho=0下的核时。平台训练使用事前验证确定的平均服务参照，不能读取当前真实类型的反事实Q0。测试时可以配对计算G=Q_policy-0.95*Q0。

主要经济终点为按16类等权的Delta_global=E[R_dynamic-R_fixed_global]。主要服务条件为E[G]>=0。资格、预算（本次零返利）等物理条件逐路径检查；95%核时只是期望约束，不能称每个用户、每个类型或每条路径的保证。

验证选择先筛服务可行候选，再比较收入。测试报告均值与区间；确认性成功须Delta_global的预设单侧95%置信下界>0，且G的单侧95%置信下界>=0。若收入点估计较高但区间跨0，表述为证据不足；若服务不合格，表述为不满足当前服务约束的收益折中，不称成功。额外报告相对固定基线的百分比增益与绝对金额，不只报p值。

分层解释：

- 胜全局固定：支持未知异质市场下的自适应部署价值，可能主要来自辨别高价值与低价值市场。
- 再胜强open-loop：支持公开响应历史带来额外价值，而不仅是固定时间日程。
- 胜按类型选择的固定oracle：才支持超出“识别类型后选固定规则”的轨迹控制价值；该oracle非上界，不胜它也不否定部署价值。
- 精确理性联盟下仍能通过观察识别类型而获益：可称自适应机制/信息价值，不能称引导学习过程或改变学习均衡的证据。
- 只有弱Q学习器上获益、强响应下一失效：结论限定在指定行为模型，不称普遍反共谋机制。

八个联盟模型子组、八个独立模型子组必须分别报告；市场A/B/C/D×联盟状态×学习率16格全部列出R、Q、完成价值/数量、低报、高报与退出。总体胜出但联盟子组受损，不能表述为已验证反共谋收益。若宣称降低共谋额外损失，还须按同一需求/价值、学习率和机制策略分别运行独立与联盟响应，报告L=R_NC-R_C及其变化；合理共享可能使L<0，保留负值。

## 6. 统计计算

固定16类是本实验定义的有限总体分层，等权平均；不把16类型当成随机抽取的16个独立市场来bootstrap。随机性来自训练种子和每类独立world。

若同一world集合跨训练种子复用，数据为交叉结构D[训练种子,类型,world]。每次bootstrap先有放回抽训练种子，再在每个类型内有放回抽一组world索引，并把同一抽样用于全部方法及所抽训练种子；这样维持配对，并保留固定基线的共同测试噪声。固定方法没有训练随机性，不能人为复制十遍再当十份独立样本。

预设10,000次bootstrap，保存分析随机种子。报告训练种子均值/分布、95%双侧区间，以及主要成功检验对应的单侧下界。只有10个训练种子时应同时展示全部种子的配对增益，不以窄world区间掩盖训练不稳定。主要单一比较为dynamic对验证最佳全局fixed；对open-loop、反馈等额外确认性显著性声明使用预先规定的Holm校正，或仅报告效应和区间并标为解释性分析。

禁止把400个时隙当独立重复，禁止只汇报终点20轮，禁止只报告最佳种子、最佳类型或最有利的保持模式。

## 7. 强联盟与表示压力测试

确认性主实验外，最低限度完成下列独立压力测试，平台参数冻结，平台历史与控制正常响应。

1. 精确单轮联盟最佳响应：两用户联合报告只有16个组合。联盟已知当前菜单，枚举每个报告组合所有匹配的期望联合效用及最优整项任务装箱，选效用最大者。效用并列时选择平台期望收入最低的解，再用固定字典序破平局。每轮重新计算，不假设它沿用训练Q。该攻击精确针对单轮，而非400轮最优策略。
2. 有历史的联盟攻击：冻结平台权重而保留其记忆与行为响应，训练集中式联盟策略最大化完整400轮总效用；信息至少包含自身类型、公开菜单、自己的报告/分配/账单历史。平台代码可知；额外真实外部类型信息单列。以独立攻击训练/验证/测试拆分选择攻击者，报告多种初始化。完整长时域精确求解若不可行，明确近似攻击只给可利用性下界。
3. 规范资格类tabular/one-hot Q；学习率变化；不同初始Q；固定温度以外的探索计划。raw-rho重复标签版只能作为机制表示伪影诊断，不作为主要经济证据。
4. 延长保持期到1000轮，或停止全部控制恢复rho=0，分别测试长期回落与完全撤回；不能将200轮保持误称永久稳定。

精确理性联盟替换后学习率标签不再影响行为，因此只有4种不同市场，不把复制的8格当额外独立证据。按类型最优无服务约束固定规则的单轮最大收入乘400，是该静态理性响应目录中的期望收入上界诊断；若发现长期均值超过它，要先检查随机性、平局规则、服务/信息假设和实现，不急于声称突破。

如果时间或算力只允许部分冻结平台种子接受长时域攻击，需在查看攻击结果前固定种子子集并披露，例如训练种子序号0、4、9；不能用对攻击最稳健的事后种子代表整体。未完成历史攻击时，结果报告必须明确缺少此项，不将单轮精确响应替代成完整抗动态联盟认证。
