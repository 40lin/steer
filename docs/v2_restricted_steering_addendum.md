# 第二版受限历史策略的候选审查

本文件补充已冻结的第二版评估协议和按容量计费附录，记录进一步确定的学习策略候选。审查者在写入本文件前未读取该候选的随机验证或测试结果。主价仍固定为 `p=0.78`，不因本附录改变。

## 动态策略

- 采用仅输入公开历史的GRU PPO，不输入精确模型后验，也不输入真实需求、私有价值、真实学习权重或随机流ID。
- 动态动作限定为 `rho∈{0.5,1}`。限制来自独立买方阶段博弈的纯策略均衡检查：该动作子集用于减少已知坏纯均衡的风险，不是所有均衡或学习轨迹都安全的证明。
- 每10轮可调整一次，前200轮控制，后200轮固定最后门槛；价格全400轮承诺不变，返利为零。
- 使用十个独立训练种子、每种子约两百万个实际市场时隙的预算。精确实际步数、所有训练/验证/测试种子和检查点选择规则应写入执行清单。
- 在规范资格特征的有限16类目录上训练；表格响应、精确联盟及前瞻攻击属于冻结平台后的独立评估，不通过这些测试修改已经选定的策略。

离线模拟中的任务数与完成价值可以用于训练奖励/约束和验证筛选。这是训练目标的监督信息，不应暗中成为部署actor的输入。若在真实部署环境中也要实时使用完成价值，需另说明观测能力和估计误差；本轮不做该假设。

主检查点在验证集上先筛净收款之外的任务条件：完成作业数和完成价值均不低于旧机制固定 `rho=0.5` 的对应验证参考，再按净收款选择。如果所有检查点均不可行，保留失败状态与最接近可行者的诊断，不能将其记为“达到任务要求”。测试仍按主协议检验配对区间，不用验证点估计替代最终证据。

## 固定对照不能随动作限制缩小

新机制下四类固定门槛 `0,0.5,2/3,1` 全部保留，包括可能对学习型买方更有效的固定 `rho=0`。动态策略只允许两个动作不构成删除强固定对照的理由。不同方法使用同样的价格、匹配、服务账本与随机条件。

同机制固定参照在验证集按照按容量计费附录的规则选择；主动态相对它的增量才代表动态引导效果。新机制相对旧收费机制的收入差继续单列，避免把改账单的收益计入GRU的贡献。

## 纯均衡检查的解释边界

所有纯策略均衡都满购，并不意味着所有混合均衡满购，也不意味着固定温度的学习过程会收敛到某个高服务纯均衡。

一个可直接核验的例子是主价 `p=0.78`、市场C、`rho=1`。两名独立买方的需求均为2、作业价值均为5。申报2只能获2核VM，申报3只能获3核VM。双方同报时只有一人获配，异报时两人都获配。只考虑申报2/3时，单个买方的收益矩阵为：

|自身申报／对方申报|对方2|对方3|
|---|---:|---:|
|自身2|1.72|3.44|
|自身3|2.66|1.33|

对称混合均衡以 `q=211/305≈0.6918` 的概率申报2，其余概率申报3。两个动作的期望收益相同且为正，退出或申报1的收益为零，因而该混合也是完整行动空间中的均衡。满购概率仅为 `2q(1-q)≈0.4264`，每轮期望完成作业约为1.4264而非2。

该反例不影响集中联盟在固定容量价格下满购的逐轮最优性证明；它说明独立买方的协调问题仍然存在。若动态策略能使学习轨迹更接近高服务纯均衡，这是可以单独验证的引导价值。但不能仅凭纯策略枚举把它当作已实现的性质。

## 需要分别回答的结果

1. 账单是否确实与申报量无关，因而在同一已租VM上低报不能降账单。
2. 本固定四市场内，联盟是否没有通过牺牲当前交易来操纵未来规则的额外收益。
3. 指定学习型参与方是否能达到较高任务完成率，低价值B是否出现服务退化。
4. 受限动态策略是否超过同机制下调优固定规则；若没有，则收益主要属于收费机制。

这四个问题可以给出不同答案。完整报告保留每个答案及失败案例，不能用精确最优响应的保证代替学习过程的实测，也不能用总体均值掩盖个别市场的任务损失。
